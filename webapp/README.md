# Luxe Botanica - Premium Beauty E-Commerce

A modern, elegant e-commerce website inspired by premium beauty brands. Built with React and Vite.

![Luxe Botanica](https://images.unsplash.com/photo-1596462502278-27bfdc403348?w=800)

## ✨ Features

- **Modern UI/UX** - Clean, minimal design with soft pastel colors
- **Fully Responsive** - Works beautifully on desktop, tablet, and mobile
- **Product Catalog** - Browse products by category with filtering and sorting
- **Shopping Cart** - Add/remove items, update quantities, persistent cart
- **Checkout Flow** - Multi-step checkout with form validation
- **User Authentication** - Login/signup pages
- **Smooth Animations** - Elegant transitions and hover effects

## 🛍️ Pages

- **Homepage** - Hero banner, categories, best sellers, testimonials, newsletter
- **Shop** - Product listing with filters and sorting
- **Product Detail** - Image gallery, reviews, related products
- **Cart** - Shopping cart with order summary
- **Checkout** - Shipping and payment forms
- **Login/Signup** - User authentication

## 🚀 Tech Stack

- **React 18** - UI library
- **React Router** - Client-side routing
- **Vite** - Build tool and dev server
- **CSS3** - Custom styling with CSS variables
- **Context API** - State management for cart and auth

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/luxe-botanica.git
cd luxe-botanica
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Build

To create a production build:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
